# Guide

## What it is

Describe a goal in plain language; OpenBrowser plans and executes steps in a real Chromium browser with optional AI planners.

## Stack

`Electron`, `Chrome extension`, `TypeScript`

## Capabilities

### Three planners

Quick heuristic, Gemini, or Ollama.

### Chrome extension agent

DOM perception plus typed actions.

### Projects & traces

Save goals, plans, and rerun later.

### Approval gates

Optional human confirmation for risky actions.
