# About OpenBrowser

## Who maintains it

OpenBrowser is built and maintained by [Mediusware](https://mediusware.com), a software company that designs and ships products for clients worldwide. The source lives at [github.com/mediuswareltd/open-browser](https://github.com/mediuswareltd/open-browser).

## Why it exists

Describe a goal in plain language; OpenBrowser plans and executes steps in a real Chromium browser with optional AI planners.

We publish these tools so teams can evaluate the real software, not a slide deck: clone it, run it, and read how it is put together.

## Documentation

- Docs site: https://mediuswareltd.github.io/open-browser/
- Getting started, guide, and about pages are generated from the project README and kept next to the code under `docs/`.
