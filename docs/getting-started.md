# Getting started

Install and run **OpenBrowser** locally.

## Prerequisites

- Working knowledge of TypeScript
- Git and a terminal

## Install

```bash
git clone https://github.com/mediuswareltd/open-browser.git
cd open-browser
npm install
```

## Quick start

```bash
npm run dev
# use sidebar goal input + planner selector
```
